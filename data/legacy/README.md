- `estudo-ibam-guarulhos.jsx` — precisa expor os arrays `ORIGINAIS` e `VARIACOES` (questões)
- `guia-estudos-ibam-guarulhos.jsx` — precisa expor o array `RESUMOS`
- `flashcards-trem.html` — precisa conter um array `CARDS` embutido em `<script>`

Esta pasta é ignorada pelo git (arquivo `.gitignore`) porque o conteúdo é seu material de estudo pessoal, não código do app.
